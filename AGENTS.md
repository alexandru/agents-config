# Agents' Config

This project is my configuration for the various harnesses I'm using, currently OpenCode and Copilot CLI.

## Repository instructions

- `opencode/` and `copilot/` are Git submodules. Run Git commands for their files from the corresponding submodule working tree (for example, `git -C opencode mv ...`), not from the parent repository. Check status and diffs in the parent and both submodules.
- Never commit or push changes. Leave all work uncommitted for review.
