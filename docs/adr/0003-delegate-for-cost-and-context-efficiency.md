# Delegate for cost and context efficiency

Orchestrator's time, tokens, and context are the most expensive in a session, so it delegates broad searches, external research, build and test runs, and mechanical edits to Junior, and works directly only when a task needs few tool calls, little output, and no iteration. Orchestrator interprets evidence and makes decisions.

Delegating to another Orchestrator saves no cost, so Orchestrator does it only when the user's instructions or a skill demand it.
