# Move research discipline into a skill

Keep the external-research discipline — source ranking, the persistent cache, and the Git worktree and Maven workflows with their examples — in the shared `external-research` skill rather than in an agent prompt. Junior loads it only when researching, so the workflow costs no context during other work, and every harness shares one copy.

The skill may be absent, so agent prompts do not depend on it and may keep rules that overlap with it.
